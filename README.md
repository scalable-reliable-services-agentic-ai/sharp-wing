## Prerequirements:

- docker (default)
- [optionaly] uv (if running lockaly without docker)


## Usage:

To run this toy example paste in terminal one of those commands:

```bash
docker compose up --build
```

```bash
docker compose up --build -d
```

```bash
make setup
```

Then open:
`http://localhost:5000/`
and
`http://localhost:5003/`
